03 // Benchmarks explained
SWE-bench, GPQA and friends, decoded.

    
What each number on these sites actually measures, how to read it, and whether a gateway can change it.

  

    
Model benchmarks are not gateway benchmarks.

    

      
SWE-bench, GPQA, the Intelligence Index: these score a model. Claude Opus 5.5 gets the same SWE-bench score whether you call it through Concentrate, OpenRouter or Anthropic directly, as long as the same model is actually served with the same settings.

      
A gateway can only lose points: route you to a different or quantized provider, drop parameters, cut off long answers. So the gateway test is parity: same model, same questions, both gateways, and the scores should match each other and the published number. That's the Quality parity test above.

      
What a gateway does own: added latency, price and fees, reliability under load, and (for auto-routers) which model it picks. Those are the Speed & fees, Load and Routing quality tests.
